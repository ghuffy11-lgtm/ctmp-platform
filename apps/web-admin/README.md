# Admin Portal

Internal procurement/admin portal.

Recommended stack:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Shared UI package

Priority screens:

```text
Dashboard
Tender List
Tender Create/Edit
Tender Detail
Approval Queue
Clarification Center
Technical Evaluation Workspace
Committee Commercial Opening
Commercial Comparison
Award Recommendation
Vendor Management
Reports
Audit Log Viewer
System Configuration
```

Important UX rules:

- Commercial envelope status may be visible as metadata.
- Commercial details require explicit permission.
- Unauthorized users must not see prices, commercial documents, download actions, or exports.
- Late submissions must be visibly marked.
- Audit/security states should be clear and hard to miss.
